# Documentation Rules: docs/

All documentation files in this directory are subject to the following rules:

1. **Factual & Verified Technical Information Only:**
   - Must only contain factual, correct technical documentation derived from official documents, specifications, or verified experiments.

2. **Permitted Content:**
   - Hardware and software specifications and pinouts.
   - Operating principles, protocols, and subsystem architectures.
   - General configuration instructions and procedural how-to guides.
   - Troubleshooting matrices and configuration challenges encountered.

3. **No Setup-Specific Configurations:**
   - NEVER document configurations specific to this physical setup (e.g., macro pad key assignments like Key A–F, layer colors, LED breathing styles, or user-specific routing).
   - All setup-specific configurations belong solely in `README.md`.
   - Never duplicate configuration details between `docs/` and `README.md`.

4. **External Sources Only (No Project File Lists):**
   - Conclude each document with a list of external source links and citations used.
   - Do NOT include lists of other internal project files or roadmap cross-reference lists.
